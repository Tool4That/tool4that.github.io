Cybersecurity

Two ways in. Learning builds the concepts, from your first command to confident defender. Practice is hands-on reps: Net Drills for subnetting and Cisco IOS, Lockdown Drills for hardening Windows, Linux, FreeBSD, and Cisco IOS, and Lockdown Range for full hardening labs in your browser.

Unofficial training, independent of and unendorsed by the makers of the systems it names. Defensive skills only: practice on machines you own or are authorized to use. Progress stays in your browser.

Learning

Build the concepts and vocabulary, from your first terminal command to confident defender. New to cybersecurity? Start with Defense Ladder, the course. Know what you need? The Study Map finds any concept as you type and shows where to learn and practice it. Command Atlas looks up any command in the course and shows what it does and where you use it. Cyber PUG gives a team experimental checklists for taking over a network, coordinated from a shared Collab Tab, with a Map that draws the network from pasted command output.

  • Defense Ladder

    Start here: the course, one grade at a time.

    A free, four-grade cybersecurity course, Freshman to Senior, built on Bloom's taxonomy: 51 units across Windows, Linux, networking, security foundations, defense operations, and web and cloud, with a readiness check at the start of Sophomore, Junior, and Senior. Diagrams, drills on realistic logs, captures, and configs, a pace planner, and a glossary round it out. Works offline, and everything stays in your browser.

Practice

Hands-on reps once you know the ideas. Net Drills are timed networking drills. Lockdown Drills walk you through hardening each system step by step. Lockdown Range drops you into a full simulated machine to harden on your own, with a live Progress Check.

Lockdown Range3 tools

Full hardening labs that run in your browser without a virtual machine: Windows 11 and Windows Server, Ubuntu and Linux Mint, and a Packet Tracer-style Cisco topology. Each Range has three levels (Recruit, Operator, and Captain) plus Level 4 · Advanced · extra credit, which builds a different machine on every attempt and gives a layout code a class can share. One layout code works in all three Ranges, and each Range builds its own machine from it. Sign in, read the scenario brief, answer the investigation questions, fix the machine, and watch a live Progress Check.

  • Windows Range

    Harden the workstation. Then the server.

    Windows 11 and Windows Server 2025 hardening scenarios in your browser, in three levels (Recruit, Operator, and Captain) plus Level 4 · Advanced · extra credit, which builds a different machine on every attempt and gives a layout code a class can share. Sign in, read the scenario brief, answer the investigation questions, then fix each one with the real panels or the command line while a live Progress Check keeps count.
