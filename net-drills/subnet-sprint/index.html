    Reference: IPv6 in text

    An IPv6 address is 128 bits, written as eight groups of four hex digits split by colons: 2001:0db8:0000:0000:0000:ff00:0042:8329.

    1. Drop the leading zeros in each group: 2001:db8:0:0:0:ff00:42:8329.
    2. Replace the longest run of two or more all-zero groups with ::, once (the first run on a tie), and write the letters in lowercase: 2001:db8::ff00:42:8329.
    3. To write it out in full, expand :: into as many 0000 groups as it takes to reach eight, and pad every group to four digits.
    4. A /64 keeps the first four groups as the network: 2001:db8::/64.

    Learn it: Defense Ladder, Freshman f7, Networking fundamentals and Cisco basics (the IPv6 addresses in text detail panel).
