How these tools work

  • One file each. Open a tool here, or download it and run it from your computer, even offline.
  • Private by design. Your data stays in your browser. Each tool says exactly what it keeps.
  • Check your download. Each tool lists its SHA-256 fingerprint. Compare it with sha256sum FILE (Linux), shasum -a 256 FILE (Mac), or certutil -hashfile FILE SHA256 (Windows).
  • Built with AI. Tools are made with AI assistance and tested before release.
Independent projects, free to use. Not affiliated with any government agency. Planning aids, not professional advice.
