1. WHAT THE LAB IS (AND IS NOT)
--------------------------------------------------------------------------------
Windows Range is a single HTML page that behaves like a small Windows machine
you have been asked to secure: OEM boot screen, lock screen, sign-in, and a
Windows 11 (version 26H2) or Windows Server 2025 desktop with taskbar, Start,
Search, and a Run box. The administration tools are faithful subsets of the real
ones, with the real names, menu paths, and control types: Local Users and Groups
(lusrmgr.msc), Local Security Policy (secpol.msc), Local Group Policy Editor
(gpedit.msc), Services, Task Scheduler, Windows Defender Firewall with Advanced
Security (wf.msc), Programs and Features (appwiz.cpl), Windows Features
(optionalfeatures), Settings (Accounts, Windows Update, Remote Desktop,
Installed apps), Windows Security, the UAC slider, System Properties, File
Explorer, Notepad, and Server Manager. Windows Terminal has Command Prompt and
PowerShell tabs with the commands in section 6, including pipes, findstr,
redirection (> and >>), secedit /export and /configure, and reg query/add for
the security registry values that hardening guides such as the CIS Benchmarks
use.

Every panel and every command changes ONE machine state, and the Progress Check
re-runs the checks after each change. Security includes availability: breaking
something the Scenario Brief says the business needs (an authorized user, an
administrator, a required service) fails an availability check and costs points.
Nothing on the page touches the real computer. Progress is saved in the browser;
"Reset lab" restores the scenario's original state and keeps the best score
(like reverting a VM snapshot).

Levels: 1 Recruit lists every check as a to-do with hints (training wheels); 2
Operator shows only the remaining count per hardening area; 3 Captain shows
nothing but the checks already passed.

2. THE ROUTINE: POWER-ON TO PROGRESS CHECK
--------------------------------------------------------------------------------
  [ ] 1. Pick the scenario (level pill in the header). Click the lock screen.
  [ ] 2. Sign in with the lab account shown under the password box (it is also
         in the Scenario Brief). If "Interactive logon: Don't display last
         signed-in" is on, type the user name too.
  [ ] 3. Open Scenario Brief.txt on the Desktop. Write down the authorized
         administrators, users, required services, and policy numbers: those
         must stay available.
  [ ] 4. Evidence first: answer the investigation questions before any change
         (Defense Ladder f1:
         https://freeapp4that.store/defense-ladder/#freshman/f1). Open
         Investigation 1.txt and 2.txt in Notepad, type the answer after
         "ANSWER:", and press Ctrl+S.
  [ ] 5. Start Windows Update in the first minutes (Settings > Windows Update >
         Resume updates > Check for updates > Install all) and keep working
         while it installs.
  [ ] 6. Work by hardening area, in the same order every time (see the list
         below).
  [ ] 7. Elevate when needed: right-click a tool > Run as administrator, or
         Ctrl+Shift+Enter in Start/Run. Commands that change the machine need an
         administrator window.
  [ ] 8. Verify each area (net accounts, auditpol /get /category:*, sc query,
         netsh advfirewall show allprofiles).
  [ ] 9. Restart once near the end, after the updates you started early finish
         installing; sign in again and confirm the progress is still there.
  [ ] 10. Finish / Debrief: read every miss and its fix. Reset lab and run it
          again faster.

Hardening areas (the Operator Progress Check counts what remains in each one,
and every check below names its area). The areas and their CIS Controls: Defense
Ladder s1 (https://freeapp4that.store/defense-ladder/#sophomore/s1).
  - Account management: who has an account, passwords, expiry, history
  - Access control: who is an administrator, lockout, sign-in and UAC settings,
    and NLA
  - Secure configuration: services, firewall, features, remote access,
    unauthorized software
  - Patching: Windows Update
  - Malware defenses: Defender, planted services, and scheduled tasks
  - Audit logging: audit policy
  - Data protection: prohibited media files
  - Investigation: the two questions on the Desktop (forensics basics).

3. SCENARIO 1 - RECRUIT: KAIMANA DENTAL CLINIC — FRONT DESK PC
--------------------------------------------------------------------------------
Sign-in  labuser / Easy!2026        Host  KAIMANA-FD1
System   Windows 11 Pro, version 26H2, build 26300.9550

Scenario Brief summary
  Kaimana Dental Clinic, a two-dentist practice in Kailua. This Windows 11 PC
  sits at the front desk and runs the appointment book. The office manager
  (nalani) is the only other administrator. A temp receptionist used it over the
  summer and the dentists suspect "helpful" changes were made.
  Authorized administrators: labuser (you) - password: Easy!2026; nalani
  Authorized users: kekoa, ailani, moana, leilani
  Required services and settings:
    - No remote access of any kind is needed on this PC (no Remote Desktop, no
      remote registry).
    - The firewall must be on and Microsoft Defender must stay on.
    - Windows Update must be allowed to install updates.
  Security policy:
    - Only the two Authorized Administrators may be in the Administrators group.
    - The Guest account must be disabled.
    - Passwords must be at least 10 characters, complex, and expire regularly;
      "Password never expires" must be cleared on every account.
    - Account lockout must be configured: lock an account after 10 or fewer
      failed attempts, for 15 minutes or more.
    - Sign-in attempts must be audited.
    - Remove media files (music and video) and unauthorized software
      (file-sharing clients, games, and network scanners).
    - Remove anything an intruder planted: unknown accounts, scheduled tasks,
      and services that run from user folders.

Investigation questions
  Q1  A scheduled task on this PC runs a batch file from C:\Users\Public. What
      is the name of that task?
      ANSWER: SystemUpdaterSvc
      (Hint: Task Scheduler (taskschd.msc) > Task Scheduler Library, or:
       schtasks /query /fo LIST /v)
  Q2  Which user account (not a built-in account) has "Password never expires"
      set?
      ANSWER: kekoa
      (Hint: net user <name> shows "Password expires"; or lusrmgr.msc > Users >
       Properties)

Checks (100 points)
  [6]  Unauthorized user "dwight" removed
       area: Account management
       fix: lusrmgr.msc > Users > dwight > Delete
       or:  net user dwight /delete
       why: An account nobody authorized is a door into the machine.
  [6]  Unauthorized user "techsupport" removed
       area: Account management
       fix: lusrmgr.msc > Users > techsupport > Delete
       or:  net user techsupport /delete
       why: An account nobody authorized is a door into the machine.
  [6]  "moana" removed from the Administrators group (not an authorized
       administrator)
       area: Access control
       fix: lusrmgr.msc > Groups > Administrators > Properties > moana > Remove
       or:  net localgroup Administrators moana /delete
       why: Administrators can undo every other fix; only the administrators
            named in the Scenario Brief belong there (least privilege).
  [5]  Guest account disabled
       area: Account management
       fix: lusrmgr.msc > Guest > Properties > check "Account is disabled"
       or:  net user Guest /active:no
       why: Guest is an anonymous login with no password.
  [3]  "Password never expires" cleared on kekoa
       area: Account management
       fix: lusrmgr.msc > kekoa > Properties > uncheck "Password never expires"
       or:  Set-LocalUser -Name kekoa -PasswordNeverExpires $false
       why: A password that never expires stays valid forever once leaked.
  [6]  Minimum password length is 10 or more
       area: Account management
       fix: secpol.msc > Password Policy > Minimum password length = 12
       or:  net accounts /minpwlen:12
       why: Short passwords fall to guessing in minutes.
  [5]  Password complexity requirements enabled
       area: Account management
       fix: secpol.msc > Password Policy > "Password must meet complexity
            requirements" = Enabled
       or:  secedit /export /cfg C:\sec.inf, set PasswordComplexity = 1 in
            Notepad, then secedit /configure /db C:\Windows\security\local.sdb
            /cfg C:\sec.inf
       why: Complexity blocks "password1" and the user's own name.
  [6]  Account lockout after 1 to 10 failed attempts, with a lockout duration of
       15 minutes or more
       area: Access control
       fix: secpol.msc > Account Lockout Policy > threshold 5, duration 30,
            reset 30
       or:  net accounts /lockoutthreshold:5 /lockoutduration:30
            /lockoutwindow:30
       why: Lockout turns a million guesses into five. A duration of 0 also
            passes: it keeps the account locked until an administrator unlocks
            it.
  [5]  Audit logon events audited for Success and Failure
       area: Audit logging
       fix: secpol.msc > Audit Policy > Audit logon events = Success, Failure
       or:  auditpol /set /category:"Logon/Logoff" /success:enable
            /failure:enable
       why: No audit trail means no way to see who signed in or what changed.
  [6]  Windows Defender Firewall on for all profiles
       area: Secure configuration
       fix: Windows Security > Firewall & network protection > Domain, Private,
            Public = On
       or:  netsh advfirewall set allprofiles state on
       why: A profile that is off exposes every listening service on that
            network.
  [6]  Microsoft Defender real-time protection on
       area: Malware defenses
       fix: Windows Security > Virus & threat protection > Manage settings >
            Real-time protection = On
       or:  Set-MpPreference -DisableRealtimeMonitoring $false
       why: With real-time protection off, malware runs unchallenged.
  [6]  Windows updates installed and not paused
       area: Patching
       fix: Settings > Windows Update > Resume updates > Check for updates >
            Install all > Restart now
       why: The pending updates include fixes for publicly known
            vulnerabilities.
  [4]  Remote Registry service stopped and disabled
       area: Secure configuration
       fix: services.msc > Remote Registry > Stop, Startup type = Disabled
       or:  sc stop RemoteRegistry && sc config RemoteRegistry start= disabled
       why: Unneeded listening services are ways in; Disabled keeps them off
            after a reboot.
  [6]  Planted scheduled task "SystemUpdaterSvc" removed or disabled
       area: Malware defenses
       fix: taskschd.msc > "SystemUpdaterSvc" > Delete
       or:  schtasks /delete /tn "SystemUpdaterSvc" /f
       why: A task that runs a .bat from a public folder re-infects the machine
            on schedule.
  [4]  Rogue service "Windows System Helper" (WinSysHelper) disabled or removed
       area: Malware defenses
       fix: services.msc > "Windows System Helper" > Stop, Startup type =
            Disabled
       or:  sc stop WinSysHelper && sc delete WinSysHelper
       why: A homemade service running from a user folder is persistence for an
            intruder.
  [5]  Unauthorized software removed (TorrentBolt 3.1, GameLoop Arcade,
       PortProbe Toolkit)
       area: Secure configuration
       fix: Settings > Apps > Installed apps > ... > Uninstall (each):
            TorrentBolt 3.1, GameLoop Arcade, PortProbe Toolkit
       or:  appwiz.cpl
       why: File-sharing clients, miners, and scanners are banned by policy and
            often carry malware.
  [5]  Prohibited media files removed from user folders
       area: Data protection
       fix: File Explorer > C:\Users\<user>\Music, Videos, Downloads > Delete
       or:  del /s /a C:\Users\*.mp3 C:\Users\*.m4a C:\Users\*.wav
            C:\Users\*.flac C:\Users\*.mp4 C:\Users\*.mkv C:\Users\*.avi
            C:\Users\*.mov
       why: Policy bans media; it is also where pirated and malicious files
            hide.
  [5]  Investigation 1 answered
       fix: Answer: SystemUpdaterSvc
  [5]  Investigation 2 answered
       fix: Answer: kekoa

Availability checks (points lost if you break what the business needs)
  -6  Authorized user removed or disabled
  -5  Authorized administrator removed from Administrators
  -10  Your own account deleted, disabled, or locked out
  -5  Required service "Windows Defender Firewall" stopped or disabled
  -5  Required service "Microsoft Defender Antivirus" stopped or disabled
  -5  Windows Update service disabled

4. SCENARIO 2 - OPERATOR: HALE KULA ROBOTICS LAB — STATION 4
--------------------------------------------------------------------------------
Sign-in  labuser / Medium!2026        Host  HKROBOTICS-04
System   Windows 11 Pro, version 26H2, build 26300.9550

Scenario Brief summary
  Hale Kula High School robotics lab, shared workstation #4. Students sign in
  with their own accounts to program the team robots. The coach (coachk)
  maintains the lab PCs. Someone installed "helper" software, a student account
  seems to have become an administrator, and the PC has been slow and noisy at
  night.
  Authorized administrators: labuser (you) - password: Medium!2026; coachk
  Authorized users: tavita, hiro, pua, mele, keahi
  Required services and settings:
    - No remote access is needed: no Remote Desktop, no Remote Registry.
    - The firewall must be on for every profile; Microsoft Defender must stay
      on; Windows Update must run.
  Security policy:
    - Only the Authorized Administrators may be in the Administrators group.
    - Guest must be disabled; every account must have a password of at least 10
      characters, complex, with a history of 5 or more, a maximum age of 30 to
      90 days, and a minimum age of 1 day or more.
    - Account lockout (after 10 or fewer failed attempts, for 15 minutes or
      more) and auditing of logons and account changes are required.
    - The last signed-in user name stays hidden, and CTRL+ALT+DEL is required.
    - User Account Control stays on.
    - SMB 1.0 and the Telnet client stay off. Remove media files and
      unauthorized software (file sharing, miners, scanners, and games).
    - Accounts with blank passwords stay limited to console sign-in, and
      AutoPlay and AutoRun stay off for every drive.
    - Only the Windows default shares (ADMIN$, C$, and IPC$) stay shared on this
      workstation.

Investigation questions
  Q1  One student account (not a built-in account) was set up so that it does
      not require a password, and its password is blank. Which account is it?
      ANSWER: pua
      (Hint: net user <name> shows "Password required" (No means the account may
       have a blank password); in PowerShell, Get-LocalUser <name> lists
       PasswordRequired.)
  Q2  An inbound firewall rule was added that is not part of Windows. What TCP
      port does it allow?
      ANSWER: 4444
      (Hint: wf.msc > Inbound Rules, sort by Group, and open the rule whose
       Group sits outside the Windows set (Core Networking, File and Printer
       Sharing, and the like), or: netsh advfirewall firewall show rule
       name="Remote Helper (TCP-In)" and read the LocalPort line.)

Checks (100 points)
  [5]  Unauthorized user "svc_backup" removed
       area: Account management
       fix: lusrmgr.msc > Users > svc_backup > Delete
       or:  net user svc_backup /delete
       why: An account nobody authorized is a door into the machine.
  [4]  "hiro" removed from the Administrators group (not an authorized
       administrator)
       area: Access control
       fix: lusrmgr.msc > Groups > Administrators > Properties > hiro > Remove
       or:  net localgroup Administrators hiro /delete
       why: Administrators can undo every other fix; only the administrators
            named in the Scenario Brief belong there (least privilege).
  [5]  Blank password on account "pua" replaced with a real one
       area: Account management
       fix: lusrmgr.msc > pua > Set Password...
       or:  net user pua Str0ng-Passw0rd! /passwordreq:yes
       why: An empty password lets anyone sign in with Enter. /passwordreq:yes
            also stops the password being set back to blank.
  [3]  Guest account disabled
       area: Account management
       fix: lusrmgr.msc > Guest > Properties > check "Account is disabled"
       or:  net user Guest /active:no
       why: Guest is an anonymous login with no password.
  [4]  Minimum password length is 10 or more
       area: Account management
       fix: secpol.msc > Password Policy > Minimum password length = 12
       or:  net accounts /minpwlen:12
       why: Short passwords fall to guessing in minutes.
  [3]  Password complexity requirements enabled
       area: Account management
       fix: secpol.msc > Password Policy > "Password must meet complexity
            requirements" = Enabled
       or:  secedit /export /cfg C:\sec.inf, set PasswordComplexity = 1 in
            Notepad, then secedit /configure /db C:\Windows\security\local.sdb
            /cfg C:\sec.inf
       why: Complexity blocks "password1" and the user's own name.
  [3]  Password history of 5 or more enforced
       area: Account management
       fix: secpol.msc > Password Policy > Enforce password history = 5
       or:  net accounts /uniquepw:5
       why: Stops toggling between two favourite passwords.
  [2]  Maximum password age is between 30 and 90 days
       area: Account management
       fix: secpol.msc > Password Policy > Maximum password age = 60
       or:  net accounts /maxpwage:60
       why: 0 means passwords never expire.
  [2]  Minimum password age is 1 day or more
       area: Account management
       fix: secpol.msc > Password Policy > Minimum password age = 1
       or:  net accounts /minpwage:1
       why: Without it, users cycle through the history in seconds to reuse an
            old password. When a maximum age is set, the minimum must be lower
            than it.
  [3]  Account lockout after 1 to 10 failed attempts, with a lockout duration of
       15 minutes or more
       area: Access control
       fix: secpol.msc > Account Lockout Policy > threshold 5, duration 30,
            reset 30
       or:  net accounts /lockoutthreshold:5 /lockoutduration:30
            /lockoutwindow:30
       why: Lockout turns a million guesses into five. A duration of 0 also
            passes: it keeps the account locked until an administrator unlocks
            it.
  [3]  Audit logon events audited for Success and Failure
       area: Audit logging
       fix: secpol.msc > Audit Policy > Audit logon events = Success, Failure
       or:  auditpol /set /category:"Logon/Logoff" /success:enable
            /failure:enable
       why: No audit trail means no way to see who signed in or what changed.
  [3]  Audit account management audited for Success and Failure
       area: Audit logging
       fix: secpol.msc > Audit Policy > Audit account management = Success,
            Failure
       or:  auditpol /set /category:"Account Management" /success:enable
            /failure:enable
       why: No audit trail means no way to see who signed in or what changed.
  [2]  "Interactive logon: Don't display last signed-in" enabled
       area: Access control
       fix: secpol.msc > Security Options > "Interactive logon: Don't display
            last signed-in" = Enabled
       or:  reg add
            HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v
            DontDisplayLastUserName /t REG_DWORD /d 1 /f
       why: Showing the last user hands an attacker half of the credentials.
  [2]  CTRL+ALT+DEL required to sign in
       area: Access control
       fix: secpol.msc > Security Options > "Interactive logon: Do not require
            CTRL+ALT+DEL" = Disabled
       or:  reg add
            HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v
            DisableCAD /t REG_DWORD /d 0 /f
       why: The secure attention sequence defeats fake login screens.
  [2]  Blank-password accounts limited to console sign-in
       area: Access control
       fix: secpol.msc > Security Options > "Accounts: Limit local account use
            of blank passwords to console logon only" = Enabled
       or:  reg add HKLM\SYSTEM\CurrentControlSet\Control\Lsa /v
            LimitBlankPasswordUse /t REG_DWORD /d 1 /f
       why: With this off, an account with an empty password also signs in over
            the network (file shares and Remote Desktop), well beyond the
            keyboard.
  [3]  UAC at the default level or higher (prompts on the secure desktop)
       area: Access control
       fix: Control Panel > User Accounts > Change User Account Control settings
            > default or "Always notify"
       or:  reg add
            HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v
            ConsentPromptBehaviorAdmin /t REG_DWORD /d 5 /f  and  /v
            PromptOnSecureDesktop /d 1
       why: With UAC off, any program the user runs silently gets administrator
            power.
  [4]  Windows Defender Firewall on for all profiles
       area: Secure configuration
       fix: Windows Security > Firewall & network protection > Domain, Private,
            Public = On
       or:  netsh advfirewall set allprofiles state on
       why: A profile that is off exposes every listening service on that
            network.
  [3]  Suspicious inbound firewall rule "Remote Helper (TCP-In)" removed or
       disabled
       area: Secure configuration
       fix: wf.msc > Inbound Rules > "Remote Helper (TCP-In)" > Delete
       or:  netsh advfirewall firewall delete rule name="Remote Helper (TCP-In)"
       why: An allow-anything rule on an odd port is a planted back door.
  [3]  Unauthorized share "Tools$" removed
       area: Access control
       fix: net share Tools$ /delete
       or:  Remove-SmbShare -Name 'Tools$' -Force
       or:  compmgmt.msc > Shared Folders > Shares > Tools$ > Stop Sharing
       why: A share nobody authorized hands the folder behind it to anyone on
            the network, and a $ at the end of the name hides it from browsing.
  [3]  Microsoft Defender real-time protection on
       area: Malware defenses
       fix: Windows Security > Virus & threat protection > Manage settings >
            Real-time protection = On
       or:  Set-MpPreference -DisableRealtimeMonitoring $false
       why: With real-time protection off, malware runs unchallenged.
  [2]  AutoRun turned off for every drive type (NoDriveTypeAutoRun 255)
       area: Malware defenses
       fix: gpedit.msc > AutoPlay Policies > Turn off Autoplay = Enabled (All
            drives)
       or:  reg add
            "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer"
            /v NoDriveTypeAutoRun /t REG_DWORD /d 255 /f
       why: AutoRun starts a program from a USB drive or disc the moment it is
            inserted, the classic USB-drop infection.
  [3]  Windows updates installed and not paused
       area: Patching
       fix: Settings > Windows Update > Resume updates > Check for updates >
            Install all > Restart now
       why: The pending updates include fixes for publicly known
            vulnerabilities.
  [3]  Remote Registry service stopped and disabled
       area: Secure configuration
       fix: services.msc > Remote Registry > Stop, Startup type = Disabled
       or:  sc stop RemoteRegistry && sc config RemoteRegistry start= disabled
       why: Unneeded listening services are ways in; Disabled keeps them off
            after a reboot.
  [3]  Remote Desktop disabled (not required on this machine)
       area: Secure configuration
       fix: Settings > System > Remote Desktop = Off
       or:  reg add "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v
            fDenyTSConnections /t REG_DWORD /d 1 /f
       why: RDP exposed on a workstation is the most common ransomware entry
            point.
  [2]  Telnet Client feature turned off
       area: Secure configuration
       fix: optionalfeatures > uncheck "Telnet Client"
       or:  Disable-WindowsOptionalFeature -Online -FeatureName TelnetClient
       why: Telnet sends every keystroke, passwords included, in clear text.
  [3]  SMB 1.0/CIFS File Sharing Support feature turned off
       area: Secure configuration
       fix: optionalfeatures > uncheck "SMB 1.0/CIFS File Sharing Support"
       or:  Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol
       why: SMBv1 is the protocol WannaCry spread over.
  [4]  Unauthorized software removed (CoinSweeper Miner, TorrentBolt 3.1,
       PortProbe Toolkit, ArcadeLoop)
       area: Secure configuration
       fix: Settings > Apps > Installed apps > ... > Uninstall (each):
            CoinSweeper Miner, TorrentBolt 3.1, PortProbe Toolkit, ArcadeLoop
       or:  appwiz.cpl
       why: File-sharing clients, miners, and scanners are banned by policy and
            often carry malware.
  [4]  Prohibited media files removed from user folders
       area: Data protection

5. SCENARIO 3 - CAPTAIN: HONUA LOGISTICS — PORTAL SERVER
--------------------------------------------------------------------------------
Sign-in  labuser / Hard!2026        Host  HONUA-SRV1
System   Windows Server 2025 Standard, version 24H2, build 26100.33296

Scenario Brief summary
  Honua Logistics, a freight forwarder with a small office on Sand Island. This
  Windows Server 2025 machine hosts the internal web portal (IIS) and the HR and
  Ops file shares. Administrators manage it over Remote Desktop from the office
  LAN. The previous administrator left in a hurry and the owner wants the server
  audited.
  Authorized administrators: labuser (you) - password: Hard!2026; kahale;
    Administrator (built-in; must stay enabled on this server)
  Authorized users: dispatch1, dispatch2, hrclerk, opsmgr
  Required services and settings:
    - Remote Desktop MUST stay enabled (with Network Level Authentication) and
      reachable through the firewall.
    - The IIS web portal (World Wide Web Publishing Service) must stay running
      and allowed on port 80.
    - FTP, SMB 1.0, and the Telnet client stay off this server.
    - Windows Update, Microsoft Defender, and the firewall must stay on.
    - The HR and Ops file shares must stay shared.
  Security policy:
    - Only the Authorized Administrators may be in the Administrators or Backup
      Operators groups.
    - Guest must be disabled. Passwords: at least 12 characters, complex, 5
      remembered, a maximum age of 30 to 90 days, and a minimum age of 1 day or
      more; "Password never expires" cleared on every account. Passwords are
      stored as one-way hashes only (reversible encryption off).
    - Account lockout (after 10 or fewer failed attempts, for 15 minutes or
      more), logon auditing, and account-management auditing are required.
    - NTLMv2 only (LAN Manager authentication level 5); the last signed-in user
      name stays hidden; UAC stays on.
    - Remove unauthorized software and unauthorized scheduled jobs.
    - Microsoft Defender scans every folder on this server, with every exclusion
      removed.

Investigation questions
  Q1  Which account is a member of the Administrators group but is NOT listed in
      the Scenario Brief as an authorized administrator?
      ANSWER: backup_admin
      (Hint: net localgroup Administrators, or lusrmgr.msc > Groups >
       Administrators)
  Q2  A scheduled task runs a .bat file from C:\Users\Public. What is the name
      of that task?
      ANSWER: IISLogCleaner

Checks (100 points)
  [5]  Unauthorized user "backup_admin" removed
       area: Account management
       fix: lusrmgr.msc > Users > backup_admin > Delete
       or:  net user backup_admin /delete
       why: An account nobody authorized is a door into the machine.
  [3]  "hrclerk" removed from Backup Operators (not an authorized administrator)
       area: Access control
       fix: lusrmgr.msc > Groups > Backup Operators > Properties > hrclerk >
            Remove
       or:  net localgroup "Backup Operators" hrclerk /delete
       why: Backup Operators can read and restore every file on the machine,
            past any folder permission: an administrator-level right that
            belongs only to the administrators the brief names.
  [3]  "Password never expires" cleared on dispatch2
       area: Account management
       fix: lusrmgr.msc > dispatch2 > Properties > uncheck "Password never
            expires"
       or:  Set-LocalUser -Name dispatch2 -PasswordNeverExpires $false
       why: A password that never expires stays valid forever once leaked.
  [3]  Guest account disabled
       area: Account management
       fix: lusrmgr.msc > Guest > Properties > check "Account is disabled"
       or:  net user Guest /active:no
       why: Guest is an anonymous login with no password.
  [4]  Minimum password length is 12 or more
       area: Account management
       fix: secpol.msc > Password Policy > Minimum password length = 12
       or:  net accounts /minpwlen:12
       why: Short passwords fall to guessing in minutes.
  [3]  Password complexity requirements enabled
       area: Account management
       fix: secpol.msc > Password Policy > "Password must meet complexity
            requirements" = Enabled
       or:  secedit /export /cfg C:\sec.inf, set PasswordComplexity = 1 in
            Notepad, then secedit /configure /db C:\Windows\security\local.sdb
            /cfg C:\sec.inf
       why: Complexity blocks "password1" and the user's own name.
  [3]  Password history of 5 or more enforced
       area: Account management
       fix: secpol.msc > Password Policy > Enforce password history = 5
       or:  net accounts /uniquepw:5
       why: Stops toggling between two favourite passwords.
  [3]  Maximum password age is between 30 and 90 days
       area: Account management
       fix: secpol.msc > Password Policy > Maximum password age = 60
       or:  net accounts /maxpwage:60
       why: 0 means passwords never expire.
  [2]  Minimum password age is 1 day or more
       area: Account management
       fix: secpol.msc > Password Policy > Minimum password age = 1
       or:  net accounts /minpwage:1
       why: Without it, users cycle through the history in seconds to reuse an
            old password. When a maximum age is set, the minimum must be lower
            than it.
  [2]  Store passwords using reversible encryption disabled
       area: Account management
       fix: secpol.msc > Password Policy > "Store passwords using reversible
            encryption" = Disabled
       or:  secedit template line ClearTextPassword = 0, then secedit /configure
            /db C:\Windows\security\local.sdb /cfg C:\sec.inf
       why: Reversible encryption stores each password in a form that decrypts
            back to the plain text, so one stolen copy of the account database
            reveals every password.
  [4]  Account lockout after 1 to 10 failed attempts, with a lockout duration of
       15 minutes or more
       area: Access control
       fix: secpol.msc > Account Lockout Policy > threshold 5, duration 30,
            reset 30
       or:  net accounts /lockoutthreshold:5 /lockoutduration:30
            /lockoutwindow:30
       why: Lockout turns a million guesses into five. A duration of 0 also
            passes: it keeps the account locked until an administrator unlocks
            it.
  [3]  Audit logon events audited for Success and Failure
       area: Audit logging
       fix: secpol.msc > Audit Policy > Audit logon events = Success, Failure
       or:  auditpol /set /category:"Logon/Logoff" /success:enable
            /failure:enable
       why: No audit trail means no way to see who signed in or what changed.
  [3]  Audit account management audited for Success and Failure
       area: Audit logging
       fix: secpol.msc > Audit Policy > Audit account management = Success,
            Failure
       or:  auditpol /set /category:"Account Management" /success:enable
            /failure:enable
       why: No audit trail means no way to see who signed in or what changed.
  [2]  "Interactive logon: Don't display last signed-in" enabled
       area: Access control
       fix: secpol.msc > Security Options > "Interactive logon: Don't display
            last signed-in" = Enabled
       or:  reg add
            HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v
            DontDisplayLastUserName /t REG_DWORD /d 1 /f
       why: Showing the last user hands an attacker half of the credentials.
  [3]  LAN Manager authentication level set to NTLMv2 only (level 5)
       area: Access control
       fix: secpol.msc > Security Options > "Network security: LAN Manager
            authentication level" = Send NTLMv2 response only. Refuse LM & NTLM
       or:  reg add HKLM\SYSTEM\CurrentControlSet\Control\Lsa /v
            LmCompatibilityLevel /t REG_DWORD /d 5 /f
       why: Windows Server 2025 has removed NTLMv1, but the setting is still
            there and hardening baselines still require level 5: a lower value
            is a deliberate downgrade to undo, and on older systems the same
            policy reaches, LM and NTLMv1 responses crack in seconds.
  [3]  UAC at the default level or higher (prompts on the secure desktop)
       area: Access control
       fix: Control Panel > User Accounts > Change User Account Control settings
            > default or "Always notify"
       or:  reg add
            HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System /v
            ConsentPromptBehaviorAdmin /t REG_DWORD /d 5 /f  and  /v
            PromptOnSecureDesktop /d 1
       why: With UAC off, any program the user runs silently gets administrator
            power.
  [4]  Windows Defender Firewall on for all profiles
       area: Secure configuration
       fix: Windows Security > Firewall & network protection > Domain, Private,
            Public = On
       or:  netsh advfirewall set allprofiles state on
       why: A profile that is off exposes every listening service on that
            network.
  [3]  Suspicious inbound firewall rule "Ops Remote Helper (TCP-In)" removed or
       disabled
       area: Secure configuration
       fix: wf.msc > Inbound Rules > "Ops Remote Helper (TCP-In)" > Delete
       or:  netsh advfirewall firewall delete rule name="Ops Remote Helper
            (TCP-In)"
       why: An allow-anything rule on an odd port is a planted back door.
  [4]  FTP server removed (service stopped and feature off)
       area: Secure configuration
       fix: Uninstall-WindowsFeature -Name Web-Ftp-Server
       or:  optionalfeatures > Internet Information Services > uncheck "FTP
            Server"
       or:  Disable-WindowsOptionalFeature -Online -FeatureName IIS-FTPServer
       why: FTP sends credentials in clear text, and the Scenario Brief does not
            authorize it.
  [3]  SMB 1.0/CIFS File Sharing Support feature turned off
       area: Secure configuration
       fix: optionalfeatures > uncheck "SMB 1.0/CIFS File Sharing Support"
       or:  Disable-WindowsOptionalFeature -Online -FeatureName SMB1Protocol
       why: SMBv1 is the protocol WannaCry spread over.
  [2]  Telnet Client feature turned off
       area: Secure configuration
       fix: optionalfeatures > uncheck "Telnet Client"
       or:  Disable-WindowsOptionalFeature -Online -FeatureName TelnetClient
       why: Telnet sends every keystroke, passwords included, in clear text.
  [4]  Remote Desktop requires Network Level Authentication
       area: Access control
       fix: Settings > System > Remote Desktop > check "Require devices to use
            Network Level Authentication"
       or:  reg add "HKLM\SYSTEM\CurrentControlSet\Control\Terminal
            Server\WinStations\RDP-Tcp" /v UserAuthentication /t REG_DWORD /d 1
            /f
       why: NLA authenticates before a session is created, blocking pre-auth
            exploits.
  [4]  Microsoft Defender real-time protection on
       area: Malware defenses
       fix: Windows Security > Virus & threat protection > Manage settings >
            Real-time protection = On
       or:  Set-MpPreference -DisableRealtimeMonitoring $false
       why: With real-time protection off, malware runs unchallenged.
  [4]  Microsoft Defender exclusion for C:\Users\Public\Libraries removed
       area: Malware defenses
       fix: Windows Security > Virus & threat protection > Manage settings > Add
            or remove exclusions > C:\Users\Public\Libraries > Remove
       or:  Remove-MpPreference -ExclusionPath "C:\Users\Public\Libraries"
       why: An exclusion tells Microsoft Defender to skip a folder, so a program
            stored there runs unscanned even with real-time protection on; an
            intruder adds one for the folder their tools run from.
  [3]  Windows updates installed and not paused
       area: Patching
       fix: Settings > Windows Update > Resume updates > Check for updates >
            Install all > Restart now
       why: The pending updates include fixes for publicly known
            vulnerabilities.
  [3]  Planted scheduled task "IISLogCleaner" removed or disabled
       area: Malware defenses
       fix: taskschd.msc > "IISLogCleaner" > Delete
       or:  schtasks /delete /tn "IISLogCleaner" /f
       why: A task that runs a .bat from a public folder re-infects the machine
            on schedule.
  [3]  Rogue service "Server Health Monitor" (SrvHealthMon) disabled or removed
       area: Malware defenses
       fix: services.msc > "Server Health Monitor" > Stop, Startup type =
            Disabled
       or:  sc stop SrvHealthMon && sc delete SrvHealthMon
       why: A homemade service running from a user folder is persistence for an
            intruder.
  [4]  Unauthorized software removed (PortProbe Toolkit, TorrentBolt 3.1)
       area: Secure configuration
       fix: Settings > Apps > Installed apps > ... > Uninstall (each): PortProbe
            Toolkit, TorrentBolt 3.1
       or:  appwiz.cpl
       why: File-sharing clients, miners, and scanners are banned by policy and
            often carry malware.
  [5]  Investigation 1 answered
       fix: Answer: backup_admin
  [5]  Investigation 2 answered
       fix: Answer: IISLogCleaner

7. WHERE THE REAL MACHINE DIFFERS
--------------------------------------------------------------------------------
  - Real VMs are slow: updates take many minutes and a restart takes a minute or
    two. Take a VM snapshot before big changes; Reset lab is the equivalent
    here.
  - UAC prompts on a real machine appear for every elevation; the lab asks once
    per sign-in.
  - Windows+R cannot be captured by a web page: use Alt+R or the Run tile.
  - Registry Editor, Event Viewer, Task Manager, and most third-party programs
    sit outside the simulation. reg.exe covers only the values listed in section
    6.
  - Compliance scanners and Group Policy read the same settings the lab checks,
    but some changes only take effect after a policy refresh (gpupdate /force)
    or a restart.
  - On a real network, change only machines you own or are authorized to manage,
    and record each change in a change log.
  - Never run these commands on a computer you depend on. Practice VMs and this
    lab are the places to experiment.
  - Version notes (Windows 11 version 26H2, Windows Server 2025): WMIC is
    removed from Windows 11, so use PowerShell instead (Get-CimInstance,
    Get-HotFix, Get-LocalUser, Get-Service); Windows PowerShell 2.0, Microsoft
    Defender Application Guard, and NTLMv1 are removed; new installs of Windows
    11 22H2 and later lock an account after 10 failed sign-ins for 10 minutes by
    default.
