Lockdown Range

Full hardening labs that run in your browser without a virtual machine: Windows 11 and Windows Server, Ubuntu and Linux Mint, and a Packet Tracer-style Cisco topology. Each Range has three levels (Recruit, Operator, and Captain) plus Level 4 · Advanced · extra credit, which builds a different machine on every attempt and gives a layout code a class can share. One layout code works in all three Ranges, and each Range builds its own machine from it. Sign in, read the scenario brief, answer the investigation questions, fix the machine, and watch a live Progress Check.

Unofficial training, independent of and unendorsed by the makers of the systems it names. Simulated machines only: nothing touches your computer, and progress stays in your browser.

Sign in, read the scenario brief, answer the investigation questions, then fix each one with the real panels or the command line while a live Progress Check keeps count.

  • Cisco Range

    Secure the topology. Prove it with ping.

    A Packet Tracer-style topology in your browser: IOS consoles with ? help, abbreviations, and the exact error messages, plus PC command prompts. Three levels (Recruit, Operator, and Captain) run from one router to two switches joined by a trunk. Level 4 · Advanced · extra credit is a two-site school network with VLAN trunks, router-on-a-stick, and OSPF that builds a different Site B on every attempt and gives a layout code a class can share. A live Progress Check keeps count.
